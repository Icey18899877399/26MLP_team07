## 接入

公共 ml_core 新增原实验目录/执行入口，后端只调包。完整复现由后台任务启动独立 Python 子进程执行原模块 CLI，传入原始数据路径与新输出目录，其余采用脚本默认值。独立进程隔离 Matplotlib 全局状态，单工串行避免过度占用 CPU；结果与日志持久化。重启后未完成任务标记中断，不虚报完成。
